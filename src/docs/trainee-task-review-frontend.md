# Trainee task review frontend

- Trainees now see a delivery-note field and `ارسال برای تأیید کارشناس` on their assigned tasks.
- Submitted tasks show `در انتظار تأیید کارشناس` and cannot be closed directly by the trainee.
- Experts see pending trainee submissions in the same project task workspace, including the trainee's submission note.
- Experts can approve or reject inline. Rejection requires feedback; approved reviews are recorded in the expert work-log flow by the backend.
- Rejected tasks return to active work and the latest expert feedback is shown to the trainee.
